# Capgemini Training - Python Practice Repository

## 📌 Overview
This repository contains daily Python practice programs, assignments, and exercises completed during the Capgemini Technical Training program.

The purpose of this repository is to:
- Strengthen Python fundamentals
- Practice problem-solving skills
- Maintain structured daily coding progress
- Track learning consistency

---

## 📂 Repository Structure

Each day’s work is organized into separate Python files.

Example:

Day1_Q1.py  
Day1_Q2.py  
Day1_Q3.py  
...  
Day1_variables.py  
Day1.ipynb  

Future days will follow a similar structured format.
